# Java Learning Labの設計・実装開始指示

## 目的

完成した FE Learning Lab と同じプラットフォーム品質を保ちながら、次の実装対象である Java Learning Lab の設計と実装を開始する。

## 開始条件

- FE Learning Lab の保存・再開・履歴・復習・レスポンシブ導線を回帰させない。
- `Japan Learning Lab -> Engineer Learning Lab -> Java Learning Lab` の直接導線と戻り導線を維持する。
- Java Learning Lab は単独の直接エントリーでも成立するブランド、ローカルナビゲーション、URLを持つ。
- 淡い水色の共通基盤に Java 固有のオレンジをアクセントとして使う。
- 学習時間、残り時間、所要時間は表示しない。

## 実施内容

1. 実装候補 LAB カタログと `Engineer-License-Lab` の Java データ構造を監査し、利用可能なコース・問題・出典・互換性境界を確定する。
2. `レッスンで学ぶ` と `演習・模試で試す` の情報設計、URL、状態遷移、保存モデル、空・エラー・再開状態を設計する。
3. Java Bronze を先行し、データ根拠を確認できた範囲で Java Silver へ拡張する。
4. 回答確定、解説、前後移動、見直し、一時停止、結果、履歴、復習、再挑戦、再読み込み復元を実装する。
5. 375px、768px、1280px以上で主要フローを検証し、自動テスト、TypeScript、ESLint、ビルドを通す。
6. 変更を現在の作業ブランチへコミット・プッシュし、非公開 Sites へデプロイして実URLを最終確認する。

## 完了報告

データ根拠、実装範囲、主要導線、保存仕様、テスト結果、レスポンシブ確認、デプロイ先、未実装事項を明記する。
